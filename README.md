# 🏀 NBA 经理（单机版）

一款离线单机 NBA 球队经理游戏（Electron + React + TypeScript）。从选队、建队风格、阵容轮换、
交易、自由市场、选秀大会到季后赛与赛季奖项全流程经营，含真实 NBA 2K 评分名单与真实球员头像资源库。

## 功能亮点

- 真实名单（NBA 2K27 公开评分 · 2026-27 赛季阵容 + 自由球员 115 人）
- 18 项 2K 风格技能面板 + 总评平衡算法（均值 + 长处补偿）
- 潜力 1-10 星成长体系（18-25 黄金期 ×3 / 26-29 稳步期 ×2 × 出场时间系数，自动分配优先突出能力、单项 ≤90）
- 双位置系统（每名球员主/副两个位置，拖拽互换、能力自动适配）
- 赛季奖项（MVP/DPOY/最佳第六人/最佳新秀 + 最佳阵容/防守阵容/新秀阵容，均带场均数据）与 FMVP
- 可操作的选秀大会（每届 80 人：美国 70% 英文名 / 中国 5% 中文名 / 其他 25%；恰有 1 名总评 ≥80）
- 自由市场 7 天窗口 + 简化劳资（工资帽 1.54 亿 / 税线 1.87 亿 / 硬顶 2 亿）
- 交易估值模型（75 能力基线、每 +10 翻倍）+ 对方薪资/战绩评估拒绝明星
- 球队气质/风格（青春风暴·球星成色二选一 + 铁血·更衣室·商业三选一）与羁绊标签
- 伤病系统（同步阵容卡片）、球队动态事件处理选项、季后赛对位图与提前晋级展示

## 运行方式

```bash
npm ci            # 安装依赖（Node 18+）
npm run dev       # 开发模式（浏览器预览）
npm run build     # 仅构建前端
npm run dist      # 构建 + 打包 Windows 便携版（release/）
```

打包产物为免安装的 `NBA-Manager-x.y.z.exe`（Windows x64）。该工程从本地直接构建，无需联网。

## 项目结构

```
src/            前端与游戏引擎（React + TypeScript）
  engine/       引擎：类型/生成/模拟/赛季/交易/休赛期/奖项/自测
  ui/           界面组件
  assets/       球队 logo（NBA 官方 CDN SVG）、球员头照、主菜单背景（Pexels）
electron/       Electron 主进程（存档读写/导出导入）
tools/          数据转换与构建脚本（本地原始数据 → src/engine/realRoster.ts）
使用说明.txt     完整玩法与规则说明（含 v2.2 更新记录）
```

## 数据来源与版权

- 名单数据来自 NBA 2K27 公开评分（2kratings.com 数据源），仅供个人娱乐，请勿公开传播或商用
- 球队图标与球员头照来自 NBA 官方公开 CDN，打包为本地资源仅做个人游戏展示
- 主菜单背景图来自 Pexels 免费商用摄影（见 `tools/fetch-backdrops.mjs`）
- 劳资规则为简化版，与真实 NBA 劳资协议有差距
